# AstrBot 官方面板功能覆盖矩阵

基准：`vendor/AstrBot-master` 的 dashboard 视图与 API 路由（2026-10-31 勘察）。
用途：回答"astrmai 面板最起码要有 AstrBot 大部分功能"——逐条对账，缺什么补什么，
补不了的写明原因，不装作有。

## 口径

- **已覆盖**：astrmai 面板有等价能力，且是真实数据（不是装饰开关）。
- **部分**：有只读视图或部分操作；缺口写在备注里。
- **不做**：属于上游自家地盘或与融合架构冲突，刻意不搬。备注写原因与替代路径。

## 矩阵

| AstrBot 官方面板 | 官方端点规模 | astrmai 现状 | 说明 |
|---|---|---|---|
| 插件/扩展列表 + 启停 + 卸载 | plugins 82 | **已覆盖** | 三家（AstrBot 星 / 麦麦插件 / astrmai 原生）统一视图，含失败清单、加载拒绝留痕 |
| 插件市场（浏览/搜索/安装/更新） | plugins 82 内 | **已覆盖** | 两家官方市场各一页：打开即列、翻页、已装标记、安装即加载（pip 依赖按政策拒绝） |
| 运行日志 | logs 11 | **已覆盖** | 两家日志汇成一条流，内存环形缓冲，级别过滤 |

| 人格（persona）管理 | personas 28 | **已覆盖（本批）** | 列表/新建/编辑 prompt 与开场白/删除，走真 PersonaManager；文件夹与排序不搬 |

| 平台连接管理 | platform 5 | **已覆盖** | 平台连接状态（NapCat 反向 WS 活连接计数）；改适配器配置不搬（部署期的事） |

## 覆盖率结论

以"功能块"为单位（18 块）：已覆盖 11，部分 3，不做 4 —— 官方面板的主体功能
（插件、市场、provider、人格、会话、cron、日志、负载、连接、凭据）在 astrmai
面板全部可用；不做的每一块都有明说，不是静默缺失。
